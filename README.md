# 🐉 Vyrcord

Vyrcord is a Discord desktop mod for Windows. Customize Discord with themes, plugins, and profiles shared with other Vyrcord users.

## Features

- **Themes and plugins** — Pick the look and features you want from Vyrcord Settings.
- **Custom profiles** — Personalize your profile and share it with other Vyrcord users.
- **Booster badges** — Vyrcord server boosters get a purple pixel `+` badge. You can hide it from the Control Center.
- **Pixel dragon** — A little dragon says “hello!” when you open the Vyrcord Discord server.
- **Signed updates** — Vyrcord verifies the release signature and file checksums before installing an update.
