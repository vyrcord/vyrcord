# Download and Install Vyrcord

## First-time installation on Windows

1. Open the [latest Vyrcord release](https://github.com/vyrcord/vyrcord/releases/latest).
2. Scroll to **Assets** and download **VyrcordInstaller.exe**. This is the only file you need for installation.
3. Fully quit Discord from the Windows system tray.
4. Run **VyrcordInstaller.exe**, select your Discord installation, and click **Install Vyrcord**.
5. Open Discord again. Click the purple dragon in the top bar to open the Vyrcord Control Center.

## Moving from the old GitHub repository

If your current installation still checks `vyrist/vyrcord` for updates, install the latest **VyrcordInstaller.exe** from the new repository once. This switches your installation to the new update source, `vyrcord/vyrcord`.

## Updating Vyrcord

Open **Vyrcord Settings → Updater** and click **Check for Updates**. If an update is available, choose **Update Now** and restart Discord when prompted.

If installation or updating fails, share the exact error in the [Vyrcord Discord server](https://discord.gg/4h2asqk29Y).
